# enter-the-matrix-blade-trilogy
## Enter The Matrix — Blade 1-2-3 Remake
A remake of the **Blade** trilogy — *Blade* (1998), *Blade II* (2002), and *Blade: Trinity* (2004) — rebuilt in the **Enter the Matrix** engine, plus an original fourth game that was never made.

---

## About

All three Blade films, recreated on the *Enter the Matrix* engine: its gunplay, martial-arts combat, bullet-time, and corridor-shooter pacing, carrying the story and set pieces of the films. The trilogy ships alongside an **extra, all-new Blade game** — a continuation that never existed, built in the same engine so it plays as a true fourth entry.
